# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP and loads only in
the public demo (`GAIACP_DEMO=true`).

## [1.0.2] - 2026-11-01

- The famous names a domain search finds taken are shared with the demo's WHOIS lookup (`App\Support\Demo::FAMOUS`)

## [1.0.1] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.0.0] - 2026-10-25

- A made-up hosting panel, registrar and monitoring service for the demo: they answer from GaiaCP's own records
  and never connect anywhere
