# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.2] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.0.1] - 2026-10-24

- Its settings page is under Settings → Integrations (Settings regrouped)

## [1.0.0] - 2026-10-24

- Better Stack Uptime as a monitoring service: a server links to one of its monitors and shows Up / Down on the Servers
  list and the dashboard; going down and coming back up notify super admins in the bell. Settings → Better Stack for
  the Uptime API token (Free plan included), with Test connection
