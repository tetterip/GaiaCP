# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.0] - 2026-11-12

- Domains at ResellerClub (and other LogicBoxes resellers): register, transfer, renew, nameservers, the daily expiry sync and the EPP code
- Contact details (registrant, admin, tech, billing), private nameservers and the registrar lock (theft protection)
- Tells the client area's domain search whether a domain is free
- Test mode, for test.httpapi.com
