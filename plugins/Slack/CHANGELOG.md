# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.2] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.0.1] - 2026-10-24

- Its settings page is under Settings → Email & notifications (Settings regrouped)

## [1.0.0] - 2026-10-23

- Slack: GaiaCP's events (new orders, payments, tickets, servers down and up, …) posted to a Slack channel through
  its incoming webhook, one short message each with a link to its page in the admin area. Settings → Slack: the
  webhook URL (stored encrypted), the events and Send a test message.
