# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.3] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.0.2] - 2026-10-24

- Its settings page is under Settings → Email & notifications (Settings regrouped)

## [1.0.1] - 2026-10-24

- Dates follow Settings → General → Date format

## [1.0.0] - 2026-10-24

- Telegram bot for admins: GaiaCP's events (new orders, payments, tickets, servers down) as messages in a chat or group,
  and, when Commands is on, answers to /owed (who owes, overdue payment notices), /today, /tickets and /servers from
  that chat only. Settings → Telegram for the bot token (encrypted), Find chat ID and Send a test message
