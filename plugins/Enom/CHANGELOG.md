# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.2.1] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.2.0] - 2026-10-25

- Tells the client area's domain search whether a domain is free (Check)

## [1.1.0] - 2026-10-24

- Contact details of a domain (registrant, admin, tech, billing), read and saved at Enom
- Private nameservers: register, change and delete
- Registrar lock: read and turn on or off

## [1.0.1] - 2026-10-24

- A phone number without a country code is taken as the client's country's (it was always Greek)

## [1.0.0] - 2026-10-19

- Domains at Enom: register, transfer, renew, nameservers, the daily expiry sync, and the EPP code, which Enom emails to the domain owner
- Test mode, for Enom's reseller test environment
