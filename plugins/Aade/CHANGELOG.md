# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.3] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.0.2] - 2026-10-24

- Its settings page is under Settings → Integrations (Settings regrouped)

## [1.0.1] - 2026-10-23

- Off in a new install (it is for Greek sellers); an install that already has it keeps its switch. `GAIACP_PLUGINS_START_ENABLED` turns it on in a new install

## [1.0.0] - 2026-10-10

- ΑΑΔΕ lookup by ΑΦΜ (RgWsPublic2) on the client form, filling name, address, Δ.Ο.Υ. and profession; Settings → ΑΑΔΕ for the special access codes
