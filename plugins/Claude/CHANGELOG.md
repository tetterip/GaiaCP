# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.2] - 2026-10-26

- Its settings page moved to the new Settings → AI assistant group, and it is listed under AI assistant on Settings → Plugins

## [1.0.1] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.0.0] - 2026-10-25

- Claude (Anthropic) as the AI service of Settings → AI assistant, with your own API key (stored encrypted) and a choice of model (Claude Opus 5.5, Sonnet 5.5 or Haiku 5.5); Test connection checks the key and the model without using tokens
- Off in a new install
