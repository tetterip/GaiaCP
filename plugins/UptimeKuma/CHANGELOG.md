# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.1.2] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.1.1] - 2026-10-24

- Its settings page is under Settings → Integrations (Settings regrouped)

## [1.1.0] - 2026-10-18

- Reads each monitor's uptime ratio for 24 hours, 30 days and a year (Uptime Kuma 2.x), shown next to the uptime bar

## [1.0.0] - 2026-10-18

- Uptime Kuma as a monitoring service: a server links to one of its monitors and shows Up / Down on the Servers list
  and the dashboard; going down and coming back up notify super admins in the bell. Settings → Uptime Kuma for the
  address and API key, with Test connection
