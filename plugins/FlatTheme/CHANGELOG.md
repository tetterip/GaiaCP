# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.2.1] - 2026-10-26

- Translated into German, Spanish, French, Italian, Dutch, Polish, Brazilian Portuguese and Turkish (machine translated)

## [1.2.0] - 2026-10-19

- Styles the client area, the public order page (/cart) and sign up too, when Settings → Client area picks this theme

## [1.1.0] - 2026-10-17

- The new layout (grouped menu, the admin's card at the foot of the sidebar, inset main area, rounded cards) in
  Filament's emerald and grey, flat: no shadows, small radii, no motion

## [1.0.0] - 2026-10-17

- The admin panel's original look (Filament, emerald green, Inter) as a theme each admin can pick in Profile
