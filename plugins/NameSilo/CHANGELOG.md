# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.0] - 2026-11-12

- Domains at NameSilo: register, transfer, renew, nameservers, the daily expiry sync, and the EPP code, which NameSilo emails to the domain's administrative contact
- Contact details (registrant, admin, tech, billing), private nameservers and the registrar lock
- Tells the client area's domain search whether a domain is free, and its TLD prices (USD, 1 year) for Settings → Domain pricing → Import from registrar
- Sandbox mode, for ote.namesilo.com
