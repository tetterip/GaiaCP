# Changelog

Every version of this plugin, newest first. The version is in `plugin.json`; it ships with GaiaCP.

## [1.0.0] - 2026-11-12

- Domains at GoDaddy: register, transfer, renew, nameservers, the daily expiry sync and the EPP code
- Contact details (registrant, admin, tech, billing) and the registrar lock
- Tells the client area's domain search whether a domain is free
- Test environment switch, for GoDaddy's OTE (api.ote-godaddy.com)
