# Διαχειριστές και ασφάλεια

## Διαχειριστές

Οι Ρυθμίσεις → Ασφάλεια → **Διαχειριστές** (μόνο για υπερδιαχειριστές) δείχνουν ποιοι μπορούν να συνδεθούν στο panel,
με την τελευταία σύνδεσή τους και αν έχουν ανοιχτό τον έλεγχο δύο παραγόντων. Για κάθε διαχειριστή ορίζεις όνομα,
email, κωδικό (με κουμπί Δημιουργία), γλώσσα του panel, **Λήψη emails συστήματος** και το καμπανάκι.

Ο **Υπερδιαχειριστής** ανοίγει τα πάντα. Κάθε άλλος διαχειριστής ανοίγει μόνο τις **περιοχές** που είναι τσεκαρισμένες
στον χρήστη του· τα υπόλοιπα κρύβονται από το μενού του και απορρίπτονται αν πάει στη διεύθυνσή τους:

| Περιοχή | Ανοίγει |
|---|---|
| Πελάτες και παραγγελίες | Πελάτες, τα στοιχεία τους και τις παραγγελίες |
| Φιλοξενία, domains και άλλες υπηρεσίες | Υπηρεσίες και τις ενέργειες Λογαριασμός και Registrar |
| Ειδοποιήσεις πληρωμής και πληρωμές | Ειδοποιήσεις πληρωμής και καταχωρισμένες πληρωμές |
| Αιτήματα υποστήριξης (tickets) | Tickets, τμήματα, έτοιμες απαντήσεις, τη βάση γνώσεων |
| Πωλήσεις: leads και προσφορές | Leads και προσφορές, για έναν πωλητή που δεν πρέπει να βλέπει πληρωμές ή servers |
| Αναφορές | Αναφορές εσόδων και υπηρεσιών |
| Αρχείο ενεργειών | Ό,τι έγινε στο panel και από την ημερήσια εκτέλεση |
| Ρυθμίσεις: επιχείρηση | Εταιρεία, χρεώσεις, φόρος |
| Ρυθμίσεις: προϊόντα και domains | Προϊόντα και ρυθμίσεις domains |
| Ρυθμίσεις: email | Mail server, εμφάνιση και πρότυπα email |

Οι διαχειριστές, οι servers, οι registrars, τα πρόσθετα και οι ρυθμίσεις Σύστημα είναι μόνο για υπερδιαχειριστές. Ο
πρώτος διαχειριστής είναι υπερδιαχειριστής, και κανείς δεν μπορεί να αλλάξει τη δική του πρόσβαση. Ο πίνακας ελέγχου
και η Βοήθεια είναι ανοιχτά σε κάθε διαχειριστή.

Κλείσε το **Μπορεί να συνδεθεί** για έναν διαχειριστή που φεύγει: δεν μπορεί να συνδεθεί, και μια ανοιχτή σύνδεση
απορρίπτεται στο επόμενο κλικ του. Διαχειριστές με εγγραφές στο αρχείο ενεργειών μπορούν μόνο να απενεργοποιηθούν,
ποτέ να διαγραφούν, ώστε το αρχείο να λέει πάντα ποιος έκανε τι. Δεν μπορείς να απενεργοποιήσεις ή να διαγράψεις τον
εαυτό σου.

## Έλεγχος δύο παραγόντων

Κάθε διαχειριστής τον ανοίγει στο Προφίλ του: μετά τον κωδικό, ένας κωδικός από εφαρμογή authenticator, με κωδικούς
ανάκτησης για όταν χαθεί το κινητό. Μέχρι να ανοίξει, μια υπενθύμιση πάνω στο panel τον προτείνει. Ένας
υπερδιαχειριστής μπορεί να τον κλείσει για έναν διαχειριστή που έχασε και την εφαρμογή και τους κωδικούς
(Διαχειριστές), ή από SSH: `php artisan gaiacp:disable-2fa admin@example.com`.

Το **Ξεχάσατε τον κωδικό σας;** στη σελίδα σύνδεσης στέλνει στους ενεργούς διαχειριστές σύνδεσμο επαναφοράς· ο έλεγχος
δύο παραγόντων ζητείται κανονικά μετά.

## Ασφάλεια σύνδεσης

Ρυθμίσεις → Ασφάλεια → **Ασφάλεια σύνδεσης**: μετά από 3 λάθος κωδικούς ή κωδικούς δύο παραγόντων από μία διεύθυνση IP
μέσα σε 15 λεπτά (στη σύνδεση του admin ή της περιοχής πελατών), η διεύθυνση αυτή δεν ανοίγει τις σελίδες σύνδεσης,
εγγραφής ή ξεχασμένου κωδικού για 15 λεπτά. Άλλαξε και τους δύο αριθμούς, κλείσε τους αποκλεισμούς, ή γράψε
διευθύνσεις και εύρη που δεν αποκλείονται ποτέ, όπως το γραφείο σου. Οι **Αποκλεισμένες IP** δείχνουν τους
αποκλεισμούς, αίρουν έναν, ή αποκλείουν μια διεύθυνση με το χέρι. Τα λάθος κλειδιά του REST API μετρούν όπως οι λάθος
κωδικοί, και μια αποκλεισμένη διεύθυνση δεν παίρνει ούτε απαντήσεις από το API.

## Captcha

Οι Ρυθμίσεις → Γενικά → **Captcha** βάζουν έναν έλεγχο «δεν είμαι ρομπότ» στις φόρμες σύνδεσης, εγγραφής, ξεχασμένου
κωδικού, αναζήτησης domain και επικοινωνίας που διαλέγεις. Κάθε captcha είναι πρόσθετο: **Google reCAPTCHA** ή
**Cloudflare Turnstile**. Βάλε πρώτα τα κλειδιά του στη δική του σελίδα ρυθμίσεων και μετά διάλεξέ το εδώ.

## Πίσω από Cloudflare ή proxy

Το GaiaCP εμπιστεύεται αρχικά τις διευθύνσεις της Cloudflare, ώστε οι αποκλεισμοί και τα αρχεία να βλέπουν την
πραγματική IP του επισκέπτη. Η Υγεία συστήματος προειδοποιεί όταν η Cloudflare είναι μπροστά αλλά δεν τη
εμπιστεύεται, ή είναι ρυθμισμένη σε Flexible SSL.

## Τι κρατά μυστικό το GaiaCP

- Τα στοιχεία σύνδεσης servers, τα logins registrars, τα κλειδιά API και οι μυστικές ρυθμίσεις αποθηκεύονται
  κρυπτογραφημένα. Τα μυστικά πεδία δεν στέλνονται ποτέ πίσω στον browser σου: ένα κενό πεδίο κρατά την αποθηκευμένη
  τιμή.
- Οι κωδικοί των υπηρεσιών φαίνονται στους διαχειριστές στη φόρμα της υπηρεσίας όταν τους αποκαλύψεις, και ποτέ σε
  λίστες, αρχεία ή εξαγωγές.
- Το αρχείο modules κρύβει κωδικούς, tokens και κωδικούς EPP.

## Το αρχείο ενεργειών

Το Σύστημα → **Αρχείο ενεργειών** καταγράφει ό,τι αλλάζει κάτι: ποιος (ένας διαχειριστής, η ημερήσια εκτέλεση, ένας
πελάτης, ένα κλειδί API), τι, και πότε. Χρησιμοποίησέ το για να βρεις γιατί μια υπηρεσία είναι σε αναστολή, ποιος
καταχώρισε μια πληρωμή ή τι έκανε η ημερήσια εκτέλεση. Κάθε υπηρεσία και κάθε πελάτης έχει τη δική του καρτέλα
Ενέργειες.
