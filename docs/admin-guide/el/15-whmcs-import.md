# Μετακόμιση από το WHMCS

Οι Ρυθμίσεις → Σύστημα → **Εισαγωγή από WHMCS** αντιγράφουν τα δεδομένα του WHMCS σου στο GaiaCP. Συνδέονται στη
βάση MySQL του WHMCS και μόνο τη διαβάζουν: αρκεί ένας χρήστης MySQL μόνο για ανάγνωση. Για εισαγωγή από αντίγραφο
`.sql`, επανάφερέ το πρώτα σε μια άδεια βάση.

## Πριν ξεκινήσεις

1. Στήσε πρώτα τα βασικά του GaiaCP: την εταιρεία σου, την περιοχή, τα νομίσματα και τον φόρο (οι τιμές του WHMCS
   εισάγονται στο βασικό σου νόμισμα).
2. Πρόσθεσε τους λογαριασμούς registrar που χρησιμοποιείς (Ρυθμίσεις → Registrars), ώστε τα domains που εισάγονται να
   μπουν σε αυτούς.
3. Έχε έτοιμο το `$cc_encryption_hash` του WHMCS, από το `configuration.php` του: αποκρυπτογραφεί τους κωδικούς της
   φιλοξενίας. Χωρίς αυτό, ή για κωδικούς που δεν αποκρυπτογραφεί, δώσε ένα URL του WHMCS και στοιχεία API και το
   GaiaCP ρωτά το ίδιο το API του WHMCS (μόνο για ανάγνωση).

## Δοκιμαστική εκτέλεση, μετά εισαγωγή

Η **Δοκιμαστική εκτέλεση** δείχνει τι θα εισαγόταν και κάθε πρόβλημα που βρέθηκε, χωρίς να αποθηκεύσει τίποτα.
Διάβασε τα προβλήματα, διόρθωσε ό,τι μπορείς στο WHMCS ή στο GaiaCP, και τρέξ' τη ξανά. Η **Εισαγωγή** μετά κάνει το
ίδιο στ' αλήθεια, με τη μία: αν κάτι αποτύχει, δεν αποθηκεύεται τίποτα.

Κάθε είδος (servers, προϊόντα, πελάτες, υπηρεσίες, domains, απλήρωτα τιμολόγια) μπορεί να μείνει έξω με το κουτάκι
του. Τρέξε ξανά την εισαγωγή αργότερα για τα υπόλοιπα: ό,τι εισήχθη θυμάται, οπότε μια δεύτερη εκτέλεση προσθέτει μόνο
τα νέα. Ένας πελάτης με το ίδιο email, ένας server με το ίδιο hostname, ένα προϊόν με το ίδιο όνομα ή μια υπηρεσία με
το ίδιο domain που υπάρχει ήδη στο GaiaCP συνδέεται αντί να αντιγραφεί, και τίποτα από όσα υπάρχουν εδώ δεν αλλάζει.

Από SSH: `php artisan gaiacp:import-whmcs --dry-run`, με τα στοιχεία της βάσης ως επιλογές και `--without=domain` για
να μείνει ένα είδος έξω.

## Τι μεταφέρεται

| WHMCS | GaiaCP |
|---|---|
| Servers cPanel, Plesk και DirectAdmin | Servers (άλλοι τύποι παραλείπονται) |
| Προϊόντα, οι τιμές τους ανά κύκλο και τα τέλη ενεργοποίησης, ομάδες προϊόντων | Προϊόντα και ομάδες προϊόντων (τα προϊόντα μίας φοράς παραλείπονται) |
| Πελάτες, με ΑΦΜ και custom fields | Πελάτες· τα άλλα custom fields γίνονται πεδία πελάτη |
| Φιλοξενία και άλλες υπηρεσίες, με όνομα χρήστη, κωδικό, λήξη, κατάσταση και ακυρώσεις στο τέλος της περιόδου | Υπηρεσίες |
| Domains: όσα είναι στο easy.gr στον λογαριασμό σου easy.gr, τα άλλα μόνο για παρακολούθηση | Domains |
| Billable items | Υπηρεσίες συντήρησης |
| Απλήρωτα τιμολόγια (προαιρετικά) | Ειδοποιήσεις πληρωμής, σημειωμένες ως ήδη σταλμένες |

Δεν εισάγονται: ιστορικό πληρωμών, addons, configurable options, επαφές, τιμές TLD (όρισέ τες στις Τιμές domain) και
nameservers (τους διαβάζει ο νυχτερινός συγχρονισμός domains).

## Μετά την εισαγωγή

- Έλεγξε μερικούς πελάτες, υπηρεσίες και λήξεις απέναντι στο WHMCS.
- Τρέξε τη **Σύγκριση με τον server** σε κάθε server (δες [Servers](04-servers.md)) για να βρεις λογαριασμούς που δεν
  ταιριάζουν.
- Όρισε τις τιμές TLD και τους προτιμώμενους registrars στις Τιμές domain.
- Άνοιξε τα πρότυπα email που θέλεις, και μετά κλείσε το cron του WHMCS ώστε οι πελάτες να μην παίρνουν διπλές
  υπενθυμίσεις.
- Δες πρώτα την πρώτη ημερήσια εκτέλεση με `php artisan gaiacp:send-reminders --dry-run` πριν γίνει στ' αλήθεια.

Αυτό είναι το τελευταίο κεφάλαιο. Πίσω στα [Πρώτα βήματα](01-getting-started.md).
