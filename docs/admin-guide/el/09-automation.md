# Αυτοματισμοί

Το μεγαλύτερο μέρος της δουλειάς του GaiaCP γίνεται μόνο του, από τη γραμμή cron που τρέχει το
`php artisan schedule:run` κάθε λεπτό. Αν σταματήσει το cron, τίποτα δεν χρεώνεται και τίποτα δεν υπενθυμίζεται: το
Χρειάζονται προσοχή του πίνακα ελέγχου το λέει και χτυπά το καμπανάκι των υπερδιαχειριστών. Οι Ρυθμίσεις → Σύστημα →
**Υγεία συστήματος** δείχνουν πότε έτρεξε τελευταία φορά το cron και κάθε ημερήσια εργασία.

Ό,τι γίνεται αυτόματα γράφεται στο **Αρχείο ενεργειών** (Σύστημα → Αρχείο ενεργειών), και κάθε εργασία ελέγχει την
τρέχουσα κατάσταση πριν κάνει κάτι, οπότε μια εργασία που τρέχει δύο φορές, ή ξανά μετά από αποτυχία, δεν κάνει ποτέ
το ίδιο πράγμα δύο φορές.

## Η ημερήσια εκτέλεση

Την ώρα που ορίζουν οι Ρυθμίσεις → Χρεώσεις → **Αυτοματισμοί** → Ημερήσια εκτέλεση στις (09:00 αρχικά, στη ζώνη ώρας
σου), το GaiaCP:

1. δημιουργεί τις ειδοποιήσεις πληρωμής που πρέπει (Ρυθμίσεις → Γενικά → Δημιουργία ειδοποιήσεων πληρωμής … ημέρες
   πριν) και τις στέλνει με email·
2. στέλνει τις υπενθυμίσεις πληρωμής και τις ειδοποιήσεις καθυστέρησης τις μέρες τους (δες [Χρεώσεις](06-billing.md))·
3. πληρώνει ειδοποιήσεις από την πίστωση των πελατών, όταν είναι ανοιχτή·
4. στέλνει την ειδοποίηση για ανανέωση domain που πλησιάζει, προσθέτει τέλη καθυστέρησης σε ληγμένα domains και
   ανανεώνει τα δωρεάν domains·
5. **αναστέλλει** τη φιλοξενία που καθυστερεί περισσότερο από την **Αναστολή φιλοξενίας μετά από** (κενό = ποτέ). Η
   καταχώριση της πληρωμής αίρει την αναστολή·
6. **τερματίζει** τις υπηρεσίες που ορίστηκε να λήξουν: μια υπηρεσία με **Αυτόματος τερματισμός στο τέλος του
   κύκλου** (ενότητα Αυτοματισμοί της υπηρεσίας) δεν παίρνει άλλες ειδοποιήσεις και τερματίζεται στην επόμενη λήξη
   της. Σε ένα domain ο διακόπτης αυτός φαίνεται ως κλειστή Αυτόματη ανανέωση·
7. **ακυρώνει τις απλήρωτες παραγγελίες** μετά από όσες ημέρες λέει η Ακύρωση απλήρωτων παραγγελιών μετά από (κενό =
   ποτέ)·
8. στέλνει στους διαχειριστές μια **ημερήσια σύνοψη**: νέες και ληξιπρόθεσμες ειδοποιήσεις πληρωμής και συγχρονισμούς
   domains που άλλαξαν κάτι ή απέτυχαν. Όταν δεν υπάρχει τίποτα να πει, δεν στέλνεται email.

Η ίδια σελίδα έχει την **Κρυφή κοινοποίηση (BCC) κάθε email πελάτη στο** (ένα αντίγραφο κάθε email πελάτη για το
αρχείο σου), τις ημέρες της **Προειδοποίησης αλλαγής τιμής**, το ποσοστό της **Ειδοποίησης χρήσης** (οι λογαριασμοί
φιλοξενίας κοντά στο όριο δίσκου ή bandwidth παίρνουν email που προτείνει μεγαλύτερο πακέτο, μία φορά τον μήνα),
πόσα **Μηνύματα προς πελάτες** φεύγουν ανά λεπτό, και ποια emails πάνε στους διαχειριστές (νέα παραγγελία, νέος
πελάτης, ζητούμενες αλλαγές, αιτήματα ακύρωσης και αναβάθμισης).

## Άλλες προγραμματισμένες εργασίες

| Πότε | Τι |
|---|---|
| Κάθε λεπτό | Μηνύματα προς πελάτες σε αναμονή, webhooks, μηνύματα Slack / Discord / Telegram, το mailbox υποστήριξης |
| Κάθε 5 λεπτά | Κατάσταση των servers από την υπηρεσία παρακολούθησης |
| Κάθε ώρα | Πιστοποιητικά SSL, blacklists IP |
| 00:20 | Οι προσφορές που πέρασε η ημερομηνία τους σημειώνονται Έληξε |
| 03:30 | Σβήνονται οι παλιές γραμμές του αρχείου modules και email (Ρυθμίσεις → Αρχεία καταγραφής → Καταγραφή) |
| 04:00 | Διαβάζονται από τους registrars οι λήξεις και οι nameservers των domains |
| 04:30 | Οι servers συγκρίνονται με το GaiaCP (όταν είναι ανοιχτό) |
| 05:00 | Έλεγχος sites |
| 06:00 | Ειδοποιήσεις χρήσης φιλοξενίας |
| 07:00 | Κλείνουν τα tickets που περιμένουν τον πελάτη |
| 08:00 | Υπενθυμίσεις επικοινωνίας με leads στο καμπανάκι |

Τα αντίγραφα ασφαλείας τρέχουν την ώρα που ορίζουν οι Ρυθμίσεις → Σύστημα → Αντίγραφα ασφαλείας.

## Προεπισκόπηση πριν γίνει

Από SSH βλέπεις τι θα έκανε μια εργασία, χωρίς να το κάνει:

```
php artisan gaiacp:send-reminders --dry-run            # ειδοποιήσεις πληρωμής που δημιουργούνται και στέλνονται, ειδοποιήσεις domains
php artisan gaiacp:suspend-overdue --dry-run           # φιλοξενία που θα έμπαινε σε αναστολή
php artisan gaiacp:terminate-scheduled --dry-run       # υπηρεσίες που θα τερματίζονταν
php artisan gaiacp:cancel-unpaid-orders --dry-run      # παραγγελίες που θα ακυρώνονταν
php artisan gaiacp:daily-summary --dry-run             # η σύνοψη των διαχειριστών, και ποιοι την παίρνουν
```

Πρόσθεσε `--date=2026-12-01` στις τέσσερις πρώτες για να δεις μια μέρα μπροστά.

## Ειδοποιήσεις

Το GaiaCP σου λέει τι σε χρειάζεται με διάφορους τρόπους· διάλεξε όσους σου ταιριάζουν:

- **Το καμπανάκι** (πάνω μπάρα): νέες παραγγελίες, πληρωμές με κάρτα, tickets και απαντήσεις, servers που πέφτουν και
  επανέρχονται, κλήσεις σε panel και registrar που απέτυχαν, αιτήματα πελατών και άλλα. Κάθε διαχειριστής βλέπει μόνο
  τις περιοχές που μπορεί να ανοίξει και ποτέ τις δικές του ενέργειες· το κλείνεις στο Προφίλ.
- **Ειδοποιήσεις push**: οι ειδοποιήσεις του καμπανακιού στο κινητό ή στον υπολογιστή σου (Προφίλ → Ειδοποιήσεις
  push).
- **Emails συστήματος**: ανά διαχειριστή, με τη Λήψη emails συστήματος στον χρήστη του.
- **Slack**, **Discord** και **Telegram** (πρόσθετα, Ρυθμίσεις → Email και ειδοποιήσεις): τα γεγονότα που διαλέγεις
  δημοσιεύονται σε ένα κανάλι ή chat. Το bot του Telegram απαντά επίσης στα `/owed`, `/today`, `/tickets` και
  `/servers`.
- **Webhooks**: τα ίδια γεγονότα ως υπογεγραμμένο JSON στα δικά σου scripts, στο Zapier, το Make ή το n8n· δες
  [Πρόσθετα και διασυνδέσεις](13-plugins-and-integrations.md).
