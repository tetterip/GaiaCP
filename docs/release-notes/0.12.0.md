Clients moving from WHMCS keep their password, free orders activate in one click, and System health fixes speed from the panel.

**New**
- **What's new.** After an update, admins see once what the new version brings, with a link to these notes.
- **WHMCS logins.** The WHMCS import brings each client's login: they sign in with the email and password they had in WHMCS. For clients imported before, run the import again with only **Client logins** ticked.
- **Free orders.** An order that comes to 0 (free products, a 100% coupon) shows **Activate**: one click, no payment form.
- **Quarantine.** Expired domains still in their grace days, and hosting suspended for a while, show as Quarantine. Hosting and Domains open on the active ones and those in quarantine.
- **Speed from the panel.** System health → **Optimize now** and **Use files**, no terminal needed. GaiaCP also rebuilds its caches by itself after an update.
- **Filters.** Products by group and type; the Filters panel now opens over the page.
- **Plugins.** Email to ticket and Webhooks ship with GaiaCP. Slack, Discord and Telegram moved to the plugin catalogue.

**Security**
- The audit before this release found nothing to fix. An imported WHMCS password is checked once and then stored with GaiaCP's own hash.

**Fixed**
- Needs attention lines open just the items they count.
- A 500 on every admin page after a plugin folder was removed.

**Before you update**
- Slack, Discord and Telegram stay installed, with their settings, and update from the catalogue. A Git checkout loses their folders: install them again from Settings → System → Plugin catalogue.
- **Use files** signs everyone out once.
