More registrars, server panels and payment methods, and a plugin catalogue with a page for every plugin.

**New**
- **Registrars:** Namecheap, NameSilo, Openprovider, GoDaddy and ResellerClub. Enom reads your own TLD costs.
- **Server panels:** Virtualmin. Better login and password changes for Plesk, DirectAdmin and Enhance.
- **Payments:** Alpha Bank, Eurobank, Piraeus Bank, Nexi XPay, Mastercard Gateway and IRIS. One **Pay online** button when a notice can be paid in several ways. Stripe and PayPal payments are also checked every hour, so one whose client closed the page is still recorded.
- **Plugin catalogue:** each plugin has its own page with its changelog, and the list filters by tag, type and status. Several plugins moved from GaiaCP into the catalogue; an update keeps them installed with their settings.
- **Domains:** Request EPP code for registrars that can't give one, and Send EPP code to email one to the client.

**Security**
- Plesk logins and shortcuts only for the client's own Plesk customer.
- Catalogue zips only from the catalogue's own address, with a real size limit when unpacked.
- CSV exports can't run as spreadsheet formulas, and the same domain can't be ordered twice at the same moment.

**Fixed**
- Pages that broke with "500 Server Error" or "Error loading page" after installing, enabling or uninstalling a plugin on a cached install.
- Cancel order on a paid order keeps its payments and records a refund, so past income stays as it was.

Not yet tried against real accounts: the new registrars, Virtualmin and the bank payment plugins. Try them in a sandbox first.
