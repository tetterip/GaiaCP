A faster panel, a clearer dashboard and a client area that shows clients what needs them.

**New**
- **Faster pages.** Clicking around the admin panel and the client area loads only the new page, and starts while the pointer is on the link.
- **Dashboard.** Today's numbers at the top, Needs attention with buttons to act on each row, recent activity, and a warning when a server is nearly full.
- **Client area Home.** What waits for the client (notices to pay, suspended services, answers, domains ending), their services with a one-click login to the control panel, and a Start here for new clients.
- **Client area.** Counts in the menu, a cart that opens from the side, nameservers and auto renew changed on several domains at once, and urgent tickets (a few a month, off by default).
- **Domain search.** Spotlight TLDs such as .gr and .com shown first, and names suggested from a few words about the business (AI, off by default).

**Security**
- A Content-Security-Policy on every page (`GAIACP_CSP=report` only reports, `off` turns it off).
- Email to ticket: replies join a ticket by a secret code, not by its number alone. Fill in **Our mail server's name** under Settings → Support → Email to ticket.
- Fixes from an outside audit and from the audit before this release.

**Fixed**
- Add to cart for a domain alone when product groups are set up.
- The installer's 500 error when sending the setup code on a new install.
- Logos in emails read in Gmail and Outlook dark mode.
- Settings no longer lists the pages of disabled plugins.

**Before you update**
- Plugins with their own inline scripts need the page's nonce (see the Plugin API line in the changelog). The bank plugins from the catalogue keep working.
- If System health → Speed warns about OPcache, raise `opcache.max_accelerated_files` to 20000 (hosts such as Plesk set 1000).
